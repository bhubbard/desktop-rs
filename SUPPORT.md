# Support for desktop-rs

Thank you for using `desktop-rs`!

## Getting Help

- **Documentation**: Check out the [README.md](README.md) for quick-start, architecture overview, and command reference.
- **Bug Reports**: Open an issue on GitHub using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
- **Feature Requests**: Open an issue using our [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).
- **Discussions / Questions**: Feel free to open a GitHub Discussion or issue for general guidance.
